Выводы:
1.Подтверждение кубической сложности алгоритма
Экспериментально подтверждено, что время выполнения последовательной версии программы (1 процесс) растет пропорционально кубу размера матрицы O(n^3)
2.Эффективность распараллеливания на MPI
Использование технологии MPI позволило сократить время выполнения задачи за счет распределения вычислений между несколькими процессами:
-Наблюдается линейный рост ускорения с увеличением количества процессов.
3.Итоговый вывод
Проведенные исследования показали, что использование MPI для умножения матриц позволяет достичь значительного ускорения (до 4.6 раз при 8 процессах для больших матриц), несмотря на наличие накладных расходов. Однако для достижения максимального ускорения необходимо использовать достаточно крупные размеры матриц, чтобы время вычислений значительно превышало время передачи данных. Для малых матриц (N < 400) параллелизация через MPI может быть даже менее эффективной из-за высоких фиксированных затрат на инициализацию и коммуникацию.
